# Fonts

Self-hosted so the app never calls a font CDN. All three families are under the SIL Open Font License 1.1 (https://openfontlicense.org):

- Newsreader, by Production Type
- Figtree, by Erik Kennedy
- Frank Ruhl Libre, by Yanek Iontef (Hebrew and Latin)

These files are WOFF2 subsets of the upstream releases (Google Fonts / Fontsource).
