<h1 align="center">Binah docs</h1>
<p align="center">Daily training for understanding what you read, weighing what you hear, and saying what you mean.</p>

These pages explain how Binah works, from the daily edition and the seven games to the ratings, the golden set and the monthly benchmark, and how to run your own copy. If you're new to it, start with [What is Binah?](what-is-binah.md), which gives you the whole picture in a few minutes, and then [Install and devices](install.md). If you'd like to try one game before any of that, [stuffs.tiresia.xyz/binah](https://stuffs.tiresia.xyz/binah/) runs Technique or Fair Move? in your browser. Basically, the first three pages are for anyone, the middle ones are for using it, and the last two groups are for running it and working on it.
